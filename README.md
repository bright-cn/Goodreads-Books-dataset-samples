此 **Goodreads 图书数据集样本**包含 **2,750 条记录**，通过 **Bright Data API** 提取。

## 数据字段

| 字段名称 | 说明 |
|------------|-------------|
| `url` | 图书在 Goodreads 上的页面 URL。 |
| `id` | 每本图书在 Goodreads 上的唯一标识符。 |
| `name` | 图书标题。 |
| `author` | 图书作者。 |
| `star_rating` | 基于用户评分得出的图书平均星级评分。 |
| `num_ratings` | 图书获得的评分总数。 |
| `num_reviews` | 图书获得的评论总数。 |
| `summary` | 图书的简要介绍或摘要。 |
| `genres` | 图书所属的类别。 |
| `first_published` | 图书首次出版的年份。 |
| `about_author` | 作者信息，包括姓名和著作数量。 |
| `community_reviews` | Goodreads 社区用户发布的评论。 |
| `kindle_price` | 图书 Kindle 版的价格（如有）。 |
| `isbn` | 图书的国际标准书号。 |


## 使用场景

### 1. 市场趋势分析
分析热门类别和作者，识别当前阅读趋势并预测未来市场需求。

### 2. 情感分析
分析社区评论和评分，了解读者情感并优化图书推荐。

### 3. 竞争情报
监测竞争对手图书的评分和评论，以优化出版策略和营销活动。
